# PRD 案例库

历史优秀 PRD 案例，生成新 PRD 时可参考其结构、表达和可视化模式。

> 本案例库中所有内容均为**为教学目的编写的虚构示例**，不含任何真实业务数据。
> 添加真实案例时请先脱敏：去掉内部文档链接、Doc Token 及真实经营指标。

---

## 案例 1: 智能客服工单自动分派系统 PRD

### 基本信息

| 项目 | 信息 |
|------|------|
| 产品类型 | 新功能 |
| 文档版本 | v2.1-MVP |
| 飞书链接 | `https://<your-tenant>.feishu.cn/wiki/<WikiToken>`（示例占位） |
| Doc Token | `<DocToken>`（示例占位） |
| 核心场景 | 客服工单按一次解决率动态分派 |

### 章节结构

```
一、一句话说清楚
二、问题和目标
  - 问题（1句话）
  - 目标（表格：目标 | 怎么衡量）
三、核心机制
  - 阶段性分派策略（流程图）
  - 为什么这样设计（表格：设计点 | 解决什么问题）
四、分派计算公式
  - SVG 图表：观察期 vs 稳定期对比
  - 适用范围说明
  - 第一天公式 + 代码块
  - 第二天公式 + 代码块
  - 示例数据表（5名客服分派计算）
  - 解决率计算方式
  - 解决率为零处理
  - 新客服中途加入
五、后台页面修改
六、VIP 工单优先策略
  - SVG 图表：决策流程全链路
  - 核心原则
  - 6.1 筛选与上限规则
  - 6.2 数量限制（表格）
  - 6.3 优先级判定（表格 + 示例）
  - 6.4 全量协调规则（表格）
  - 6.5 降级回退逻辑
七、分派效果数据统计
  - SVG 图表：三层指标体系
  - 合并表格（分类 | 指标 | 作用）
```

### 可视化亮点

1. **分派公式图解**（第四章）
   - 左右分栏对比观察期 vs 稳定期
   - 蓝色系表示观察期，绿色系表示稳定期
   - 箭头连接展示流程

2. **VIP 工单决策流程**（第六章）
   - 纵向流程图，5个决策节点
   - 每个节点配说明文字
   - 底部展示保护机制

3. **数据指标体系**（第七章）
   - 三层架构图
   - 实时看板 → 策略效果 → 数据预期
   - 每层标注核心指标

### 表达亮点

- 一句话说清楚：**"所有客服先平等接一批工单，之后按一次解决率每日动态分派——解决得好的多接，差的少接但不闲置。"**
- 问题描述：**"客服抢工单靠手速，谁手快谁接，解决质量没人管。"**
- Non-goals 明确：7 条，每条附注理由
- 公式配完整数字举例：5名客服、2000 单的分派计算表
- 异常处理场景化：6 种具体场景 + 处理方案

### 关键参数

| 参数 | 值 |
|------|-----|
| 日均工单量 | ~2000（示例值） |
| 考核周期 | 5天 |
| 分派调整频率 | 每日1次 |
| 保底比例 | 10% |
| VIP/普通划分 | 30%/70% |

## 如何使用案例库

### 匹配相似场景

1. 分析新需求的类型（新功能/迭代/重构）
2. 在案例库中找到同类型案例
3. 参考其章节结构和表达方式
4. 可视化模式按需复用

### 添加新案例

当完成一份高质量 PRD 后，将其添加到案例库：

1. 记录基本信息（类型、核心场景）
2. 提取章节结构
3. 记录可视化和表达亮点
4. 总结关键参数

⚠️ **添加前必须脱敏**：

- 内部文档链接 / Doc Token → 占位符
- 真实经营指标（DAU、GMV、转化率等）→ 示例值或数量级描述
- 内部管理问题描述 → 抽象为通用场景

格式参照案例 1 的结构。
